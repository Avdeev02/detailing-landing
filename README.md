# Northline Detailing - landing page (demo)

A one-page site for a fictional car detailing studio. Built as a portfolio project.

**Live demo:** https://lilbro228.github.io/detailing-landing/

## Features

- Responsive layout: works on desktop and phone, with a mobile menu
- Price calculator: service, car size and extras update the estimate instantly
- Contact form with validation
- Single HTML file, no frameworks or build step, loads fast

## Tech

HTML, CSS, vanilla JavaScript.

## Note

The contact form is a demo and does not send data anywhere. For a real client it can be connected to email or a Telegram bot.
